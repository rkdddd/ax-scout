# AX SCOUT 디자인 시스템

토스에서 영감을 받은 밝고 친근한 톤입니다. 화면을 그대로 따라 하지 않으며, 토스의 로고와 전용 글꼴은 쓰지 않습니다.
토큰은 [app/globals.css](../app/globals.css)에 정의돼 있고, 컴포넌트는 shadcn/ui(`components/ui/`)를 이 값에 맞춰 조정해 씁니다.

## 원칙

1. **무엇을 해야 하는지 바로 보이게 한다.** 화면마다 가장 중요한 행동 하나만 파란 버튼으로 둔다.
2. **짧은 문장으로 안내한다.** "~해요" 체를 쓰고, 한 문장에 한 가지만 말한다.
3. **그림자와 테두리를 아낀다.** 회색 바탕 위에 흰 카드를 올려 구분한다.
4. **상태를 정성껏 보여준다.** 빈 화면, 불러오는 중, 오류, 저장 완료에 모두 전용 화면을 둔다.

## 색

| 이름 | 값 | 쓰임 |
|---|---|---|
| background | `#FFFFFF` | 카드, 상단 바 |
| surface | `#F2F4F6` | 화면 전체 바탕, 비활성 칸 |
| foreground | `#191F28` | 주요 글자 |
| muted-foreground | `#6B7684` | 보조 글자 |
| primary | `#3182F6` | 포인트(주요 버튼, 링크, 선택 상태) |
| accent | `#E8F3FF` / 글자 `#1B64DA` | 연한 파랑(보조 버튼, 안내 상자) |
| border | `#E5E8EB` | 구분선 |
| destructive | `#F04452` | 오류 |
| success | `#03824F` / 바탕 `#E6F7EF` | 완료, 저장됨 |
| warning | `#B86E00` / 바탕 `#FFF4E0` | 진행 중 |

공모전 단계 색: 관심(회색) → 검토(파랑) → 참가 진행(주황) → 완료(초록).

## 글꼴·글자 크기

- 글꼴: **Pretendard** (가변 글꼴, `next/font/local`로 프로젝트에 포함). 한글은 단어 단위로 줄바꿈(`word-break: keep-all`).
- 화면 제목 28px 굵게 · 카드 제목 17px 굵게 · 본문 15px · 보조 설명 14px · 작은 표시 12px
- 글자 간격은 제목일수록 좁게(`-0.03em`).

## 모양

- 모서리: 입력칸·버튼 12px(`rounded-xl`), 큰 버튼 16px, 카드 24px(`rounded-3xl`), 배지는 완전 둥글게.
- 간격: 화면 좌우 20px, 카드 안쪽 24px, 항목 사이 16px.
- 입력칸: 회색으로 채워져 있고, 누르면 흰 바탕에 파란 테두리가 켜진다. 높이 48px.
- 버튼: 기본 44px · 큰 버튼 56px. 종류는 `default`(파랑, 가장 중요) / `tonal`(연한 파랑) / `secondary`(회색) / `ghost` / `destructive`.

## 움직임

- 누르거나 마우스를 올릴 때 색이 150ms 동안 부드럽게 바뀐다.
- 버튼을 누르면 2% 작아졌다 돌아온다.
- 저장 완료 알림은 위에서 살짝 내려오고 3.5초 뒤 사라진다.
- "움직임 줄이기" 설정을 켠 사용자에게는 움직임을 거의 없앤다.

## 공통 부품

| 파일 | 역할 |
|---|---|
| `components/page-header.tsx` | 화면 제목 + 설명 + 대표 행동 |
| `components/empty-state.tsx` | 빈 화면·오류·준비 중 안내 |
| `components/flash-notice.tsx` | 저장 완료 알림 |
| `components/submit-button.tsx` | 저장 중 자동으로 눌리지 않는 버튼 |
| `components/stage-badge.tsx` | 공모전 단계 배지 |
| `components/main-nav.tsx` | 상단 메뉴 |

## 앞으로 만들 화면에 적용할 방향

- **대시보드(PLAN 12):** 숫자를 크게 보여주는 지표 카드와 "오늘 확인할 정보". 지금 홈의 카드 구성을 확장한다.
- **공고(PLAN 17·18):** 카드형 목록, 마감일까지 남은 날(D-day)과 상태 표시, 칩 필터.
- **활동실적(PLAN 10·11):** 날짜 순 타임라인 + 유형별 칩 필터.
- **보고서:** PRD에서 "나중에 구현할 것"으로 미뤘으므로 이번에는 만들지 않는다.
